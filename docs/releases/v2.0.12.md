## Compatibility

### Analysis report JSON

- Emits: schema v2.
- Imports: valid schema v1 and schema v2.
- Rejects: version 0, unsupported future versions, malformed/oversized/inconsistent report data.
- Legacy v1 vocabulary fields absent from the old format are not shown as meaningful measured deltas.
- Raw analyzed text and full source paths remain outside the canonical report contract.

### Settings backup

- Current backup schema: v2.
- Compatible legacy schema-v1 restore remains supported with documented defaults for newer preferences.

### Dependency/toolchain reproducibility

- `package-lock.json` is committed and clean installs use `npm ci`.
- `src-tauri/Cargo.lock` is committed and Rust CI/release paths use Cargo `--locked` verification where applicable.
- Dependency manifest changes must include the corresponding package-manager-generated lockfile diff.
- `rust-version = 1.77.2` is no longer documentation-only: CI contains a dedicated MSRV check for the committed Cargo graph.

## Privacy/security boundaries retained

- no account required;
- no analytics SDK;
- no cloud text-processing API;
- no background update polling;
- document contents processed locally;
- report exports omit raw source text;
- recent history is opt-in and path-free;
- storage failure does not trigger a network fallback;
- missing destination errors do not echo private directory paths;
- release checksum manifest verification rejects unsafe/traversing paths and digest mismatches;
- dependency security checks operate on committed package-manager lockfiles rather than regenerating an unreviewed graph during audit.
