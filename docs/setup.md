# Setup

TextLens has desktop, Web/PWA, Android, and iOS/iPadOS build paths. The shared prerequisites come first; install only the platform toolchains needed for the targets you build.

See [platforms.md](platforms.md) for the full support matrix and runtime differences.

## Node.js

Use Node.js 20.19+ or 22.12+. Node.js 22 LTS is a good default.

```bash
node --version
npm --version
```

Install JavaScript dependencies after cloning:

```bash
npm install
```

## Rust

Rust is required for Tauri desktop and mobile packaging. Pure Web/PWA development can use the portable frontend without compiling Rust.

Install Rust with `rustup` and select stable:

```bash
rustup toolchain install stable
rustup default stable
rustc --version
cargo --version
```

## Desktop Tauri prerequisites

### Windows

Install Visual Studio 2022/Build Tools with **Desktop development with C++**, a current Windows SDK, and ensure Microsoft Edge WebView2 Runtime is present.

### macOS

```bash
xcode-select --install
```

Apple signing/notarization is needed for signed public releases, not ordinary local development.

### Debian/Ubuntu Linux

Typical Tauri 2 packages:

```bash
sudo apt update
sudo apt install -y \
  libwebkit2gtk-4.1-dev \
  build-essential \
  curl \
  wget \
  file \
  libxdo-dev \
  libssl-dev \
  libayatana-appindicator3-dev \
  librsvg2-dev \
  patchelf
```

Package names vary by distribution.

## Clone

```bash
git clone https://github.com/sanskarIN/textlens.git
cd textlens
npm install
```

## Desktop development

```bash
npm run tauri:dev
```

Desktop package build:

```bash
npm run tauri:build
```

## Web and PWA development

The web build does not require Rust after JavaScript dependencies are installed.

```bash
npm run dev:web
```

Production static/PWA bundle:

```bash
npm run build:web
npm run preview:web
```

Production PWA hosting must use HTTPS and serve the generated `dist/` files with correct MIME types. `manifest.webmanifest`, `sw.js`, and the install icons must remain reachable from the application root.

## Android development

Install the current Tauri Android prerequisites on the development machine, including:

- Rust stable;
- the Android Rust targets required by Tauri;
- a JDK suitable for Android development;
- Android Studio;
- Android SDK/platform/build tools;
- an emulator or physical Android device.

When the generated Android project has not been initialized in the checkout, run:

```bash
npm run tauri:android:init
```

Development:

```bash
npm run tauri:android:dev
```

Build:

```bash
npm run tauri:android:build
```

`src-tauri/tauri.android.conf.json` selects the portable `mobile` analyzer mode and enables the capability-restricted global Tauri bridge. Android's native document picker returns a `content://` provider URI; TextLens uses the Tauri filesystem plugin only to stat/read the selected input or write an explicitly selected save destination. Provider URIs are not passed to the desktop Rust `std::fs` analysis path.

Play Store signing, target-SDK policy checks, AAB/APK signing, screenshots, and store submission are release-environment gates.

## iPhone and iPad development

iOS/iPadOS development requires a macOS host. Install:

- Xcode and Xcode command-line tools;
- Rust stable;
- the iOS Rust targets required by Tauri;
- an iOS Simulator or physical device.

When the generated iOS project has not been initialized in the checkout, run:

```bash
npm run tauri:ios:init
```

Development:

```bash
npm run tauri:ios:dev
```

Build:

```bash
npm run tauri:ios:build
```

`src-tauri/tauri.ios.conf.json` selects the same portable analyzer mode and scoped native bridge. iOS/iPadOS document selection returns a `file://` URI that is read/written through the Tauri filesystem plugin only after explicit user interaction.

App Store signing, provisioning profiles, privacy declarations, screenshots, archive validation, and submission remain release-environment gates.

## ChromeOS

Use the Web/PWA path. Build the PWA with:

```bash
npm run build:web
```

After deployment over HTTPS, compatible ChromeOS browsers can run or install the PWA without a separate ChromeOS-native codebase.

## Validate toolchains

Run the frontend, documentation, and Rust quality gates before opening a pull request:

```bash
npm run version:check
npm run check
npm run lint
npm run format:check
npm run docs:check
npm run test
npm run build
npm run build:web
npm run build:mobile

cd src-tauri
cargo fmt --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test --all-targets
```

`npm run docs:check` verifies repository-local Markdown link and image targets without making network requests.

The frontend CI verifies native desktop, Web/PWA, and mobile frontend bundles. Signed/native device packages must additionally be tested in their required platform environments.

## Dependency lockfiles

Release candidates should commit refreshed npm and Cargo lockfiles generated by their normal package managers in an environment with registry access. Do not hand-edit or invent lockfiles.

## Configuration

Copy `.env.example` only when overriding local defaults. `TEXTLENS_LARGE_FILE_THRESHOLD_MIB` accepts 1..1024 and defaults to 8 MiB for the native Rust file path. The portable Web/mobile analyzer has a separate fixed 64 MiB in-memory selected-source safety bound.

No credential is needed for core analysis.
